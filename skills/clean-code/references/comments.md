# Comments

Prefer code that makes comments unnecessary. Comments explain why, not what.

- Delete comments that restate the next line.
- Keep comments that record a constraint, a workaround, or a non-obvious tradeoff.
- Do not leave one-off timings or investigation notes in code.
- Do not comment out dead blocks. Delete them or `use fire`.
- If a comment is apologizing for the code, simplify the code instead.
- Match the language already used in nearby comments.
